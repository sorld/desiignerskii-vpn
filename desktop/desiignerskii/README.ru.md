# Desiignerskii VPN Desktop 0.5.1

Клиент для Windows 10/11 x64 с движком Throne 1.4.2 (a7986a03e978952b585ee1d24b6d8f2a48f7df41).

## Первый запуск

Распакуй ZIP целиком в постоянную папку и запусти Desiignerskii VPN.exe. Нужен Microsoft Edge WebView2 Runtime. Нажми «Добавить устройство» и вставь ссылку устройства из личного кабинета (/s/… или /join/…). Выбери сервер в списке на главном экране. Нажми «Подключить» на главном экране.

По умолчанию включается полный туннель TUN. При первом подключении Windows может запросить подтверждение для Throne.exe. Штатный механизм Throne выдаёт права сетевому движку для этого пользователя и этой папки программы. Окно клиента работает с обычными правами. Закрытие запроса отменяет подключение. Если уже запущен TUN другого клиента, отключи его перед подключением.

Перед показом статуса «VPN включён» клиент проверяет режим и профиль в Throne, маршрут Windows к адресу проверочного HTTPS-запроса и ответ через адаптер throne-tun. Режим «Системный прокси» доступен в настройках и сохраняется только по явному выбору. Если TUN не удалось запустить, клиент покажет причину. Режим подключения можно поменять после отключения.

В списке серверов доступны поиск, избранные и проверка задержки. Нажатие другого сервера при активном подключении переключает соединение. Таймер отсчитывается с начала текущего сеанса, счётчики показывают накопленный трафик выбранного профиля по данным Throne. Сворачивание сохраняет соединение, выход закрывает его.

Устройства и подписки предыдущей версии остаются в %LOCALAPPDATA%\Desiignerskii VPN. При обновлении сначала выйди из предыдущей версии через трей.

## Настройки

Раздел «Настройки» читает параметры установленного движка. В «Туннеле» можно менять MTU, IPv4/IPv6-адреса адаптера, IPv6 и строгую маршрутизацию. В DNS задаются резолверы для туннеля и прямого трафика и локальный порт. В «Подписках» доступны интервалы обновления подписок и удалённых маршрутов. В «Диагностике» — адрес для измерения задержки, тайм-аут, параллельность, уровень журнала и последние 80 записей.

В «Маршрутизации» выбери профиль и добавь сайт или имя EXE в нужный список. Можно редактировать записи построчно, например `suffix:example.org` и `processName:app.exe`. В режиме системного прокси правила действуют на трафик, который приложения передали прокси. Маршруты из подписки и профили с внешней или произвольной конфигурацией открываются для просмотра. Группа подписки может использовать собственный маршрут вместо выбранного по умолчанию.

Кнопка «Сохранить» передаёт движку только изменённые поля открытого раздела. Если для применения нужно перезапустить профиль, клиент предложит переподключиться. Сеанс продолжается, пока ты сам не нажмёшь «Переподключиться» или «Отключить».

Состояние соединения, кнопка подключения и список серверов видны в одном окне. Нажатие на текущий сервер переносит курсор в поиск. Полоса трафика показывает доли принятого и отправленного трафика выбранного профиля за всё время.

## Сборка

Нужен Go 1.27.4. Открой PowerShell в desktop/desiignerskii и выполни:

```powershell
.\build-windows.ps1
```

Скрипт скачивает архив официального Throne 1.4.2, проверяет SHA-256 и собирает исполняемый файл со встроенным интерфейсом. Результат находится в новой папке build под именем Desiignerskii-VPN-0.5.1-windows-x64. Исходники движка и штатные сценарии его сборки входят в корень форка. Для проверки модели клиента выполни go test ./... в этой папке.

## История Git

Пакет исходников включает рабочее дерево и файл Desiignerskii-Throne.bundle. Чтобы развернуть форк с историей:

```powershell
git clone -b desiignerskii .\Desiignerskii-Throne.bundle Desiignerskii-Throne
cd Desiignerskii-Throne
git remote add upstream https://github.com/throneproj/Throne.git
```
